Hyper-Brain 0.2.1

2026-09-10。项目名称改为 Hyper-Brain，保留 hic-brain Python 分发名、hicbrain API / 命令及旧结果兼容性。

超边显示改进

  • 球、普通边和骨架改为逐实例 / 逐顶点的真实透明度，不再用背景色模拟淡出；透明物体不会继续写入深度、挡住所选结构。
  • 全局超边使用更轻的包络面与细轮廓，密集超边只降低视觉强度，不删除结构；骨架使用轻微曲线和较小的空心锚点。
  • 当前超边及其完整成员最突出；当前节点比关联节点更突出。无关节点 / 标签不透明度 2.5%，无关连接 / 轮廓 0.9%，无关包络 / 分区面 0.2%。
  • 成员标签优先排布；当前选择的拾取优先于淡化背景；重叠候选仍可逐个选择。全局脑表面参数与数据坐标不变。

已执行验证

  • 138 项 Python 测试、8 项前端测试、Ruff、TypeScript 检查及生产构建通过。
  • 使用同一合成 116 ROI 网络，对比修改前后全局、超边选中、节点选中与深浅皮肤的实际截图；检查控制台没有着色器错误。
  • 116 ROI 的全部八种组合通过；90 / 200 / 400 ROI 的包络、骨架与分区表面保留全部节点、普通边、超边及全局缩写。
  • 重新检查实际三维拾取、旋转 / 平移 / 缩放、图谱切片、热图 / 成员表联动、PNG / JSON 导出与保存 / 恢复。
  • 导出连接矩阵、普通图和完整原生超图与源分析一致；同成员、不同 ID 的超边保持独立。
  • 浏览器阻断所有非本地 HTTP(S) 请求后，八种组合与 NiiVue 切片正常，没有外部请求或失败的资源响应。
