四病数据来源

  • ASD：ABIDE I、ABIDE II。
  • ADHD：ADHD-200。
  • MDD：REST-meta-MDD、SRPBS。
  • AD/认知障碍：ADNI、OASIS-3。

ADNI 是队列名称。个体级数据和衍生物依各自协议使用，不随工具再分发。ROI超图、受试者群体超图、形态网络与fMRI网络须分别记录；超图表征不自动证明不可约高阶关系。
