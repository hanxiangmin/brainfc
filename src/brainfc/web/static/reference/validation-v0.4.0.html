0.4.0 合并验证

本次把 Hyper-Brain 网络分析合入 BrainFC，保留影像/时间域处理与结构分析的职责边界。

已完成

  • Windows / Linux × Python 3.11 / 3.12：206 项测试通过，涵盖提取、格式、引导、图谱、图/超图/统计以及真实样例与来源校验。
  • 独立运行已安装的 Hyper-Brain 0.3.0 与合并后的实现；5 种图方法 × 4 种超图方法，共 20 组配置，完整矩阵、ROI ID、图/超图结构、指标、配置和布局完全一致。比较排除时间戳、软件版本等必然变化的运行记录。
  • 提取到网络的新增集成测试：不调用时序相关估计；保留 ROI 顺序、帧号、坐标和来源；重复调用复用已准备输入；界面默认值不能覆盖已提取矩阵的语义；错误 ROI/JSON 被拒绝。
  • 两套前端类型检查与生产构建通过；原生超边 ID、选择、重复成员集合等 8 项前端测试通过。
  • 真实浏览器端到端：默认 rest01 提取、矩阵定位、3D/八视图同步、自动进入网络方法确认、后台分析、继承参考几何、不下载图谱、超图包络、结果导出、离线报告和手机尺寸手册。核对 100 个脑区、145 帧以及非合成来源记录。
  • 网页采用工大蓝、白色与浅蓝底色，两块工作台使用一致的操作色；默认三维视图为浅色。数据色标保持原有含义，见网页配色。
  • 93 个 Python API 条目与 36 个 HTTP 路径自动生成；网络服务 OpenAPI 与主服务分别保存，离线手册包含迁入方法说明。
  • wheel/sdist 构建及 Twine 元数据检查通过；发行物包含网络界面和兼容入口；rest01 文件集与审核 SHA-256 完全匹配。

旧 Hyper-Brain 的历史验证记录保存在 docs/network/validation*.md，描述的是上游当时环境；它们不等于本次的新增验证。当前主分支的跨系统结果以 GitHub CI 为准。

保留的边界

  • 本次不改变原始影像预处理范围，不新增诊断预测或高阶生理相互作用结论。
  • 直接转入的参考表面不等于完整分区图谱；没有分区表面/图谱体积时不启用相应显示。
  • 不自动迁移旧工作区、不删除旧仓库；旧 HTTP 客户端切换到统一服务时要加 /networks 前缀。
  • 旧 hic-brain distribution 与新包共享兼容命名空间，升级同一环境前需要移除旧 distribution，再安装 BrainFC。
  • 本次合并没有增加真实样例的公开范围；原始 DICOM、个体 T1/BOLD 强度图像和私人处理日志仍不进入发行包。
