# rest01 发布前隐私核查

## 公开范围

公开的是脑区时间序列、混杂变量、ROI 名称/坐标、必要参数、二值脑组织显示掩膜和处理说明。文件位于 `src/brainfc/data/rest01/`。

原始 DICOM、个体 T1/BOLD 影像、检查报告、转换日志、原始文件名/路径、内部核查图页和本地影像 ZIP 均不上传。显示掩膜只有 0/1，不包含原始扫描灰度；它仍属于个体衍生的脑组织轮廓。

## 已执行的核查

- 对照所选序列的 913 个原始 DICOM 头，检查姓名、患者编号、出生/检查日期、联系方式、机构、设备标识、UID，以及嵌套的人名字段。匹配值只在本地使用，不写进公开报告。
- 检查候选公开文件及构建后的 wheel/sdist，包括文本、图像元数据和压缩的 NIfTI 头。新建 NIfTI 头的自由文本字段和扩展为空。
- 掩膜按三个方向展开全部切片，核查实际像素；同时检查仓库展示图及本地输出图。
- 对本地保留的脑组织 T1 展开全部 520 个采集切片；对 BOLD 展开全部 150 帧、每帧 81 个切片。Tesseract 5.5.0 的中英文识别覆盖共 198 张图页，未匹配到已知身份标识。中英文人工文字对照通过。原始 `BurnedInAnnotation` 均为 `NO`，但没有仅凭这个标签作结论。
- 脱敏范围不等于绝对匿名：真实脑信号与衍生脑组织轮廓仍可能具有个体特征；OCR 也不能证明不存在任何可能的文字。这里报告的是执行过的检查及其结果，不是法律合规认证或不可再识别保证。

## 防止误打包

`privacy-review.json` 保存已核查的七个样例文件的 SHA-256，不含原始数据的身份字段或原始 DICOM 指纹。发行物检查要求文件清单和校验值完全匹配；新增或修改样例文件必须重新核查并更新记录。原始 DICOM 和个体强度影像不在允许范围内。

软件维护者的公开 GitHub 账号、版权及第三方作者署名属于项目文档，不用于标注或推断样例被试身份。

像素文字与文件头需要分别检查的依据见 [DICOM PS3.15 的 Clean Pixel Data 说明](https://dicom.nema.org/medical/dicom/2024a/output/chtml/part15/sect_E.3.html)。本项目没有声称执行完整 DICOM 保密配置；发布样例中不包含 DICOM。
