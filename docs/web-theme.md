# 网页配色

BrainFC 的提取工作台、网络分析工作台和离线手册统一采用工大蓝、白色与浅蓝底色。

颜色依据：[北京工业大学建筑工程学院公布的工大蓝标准色](https://cace.bjut.edu.cn/info/1076/1475.htm)。页面标准色图列出 RGB **0 / 150 / 195**，对应网页色值 **`#0096C3`**。这是配色参考，不表示学校对本项目的认证或背书。

| 用途 | 色值 | 说明 |
| --- | --- | --- |
| 品牌标记 | `#0096C3` | 官方工大蓝 |
| 按钮、链接、选中操作 | `#007DA3` | 为网页可读性加深的衍生色；白字对比度约 4.6:1 |
| 悬停操作 | `#005F7D` | 深蓝 |
| 页面 / 信息底色 | `#F5FAFC` / `#EAF5FA` | 浅蓝 |
| 内容卡片 | `#FFFFFF` | 白色 |
| 正文 / 次要文字 | `#18354A` / `#526C7A` | 深蓝与蓝灰 |

两套界面使用同名 CSS 变量。默认三维视图使用浅色主题；深色查看模式仍可手动选择。状态信息由文字、图标和边框区分，避免仅靠颜色传达处理结果。

本次调整只针对网页样式。功能连接矩阵的正负色标、脑区分类、超边颜色及相应图例继续表达数据含义，不随网页主题改变；导出的矩阵数值与分析结果不变。
